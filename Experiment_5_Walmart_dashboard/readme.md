# 📊 Walmart Sales Dashboard (2011–2014)

## Overview
An interactive Power BI dashboard developed using the Walmart Sales Dataset to analyze sales, profit, quantity, and product performance from 2011 to 2014.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Dataset
- Walmart Sales Dataset (2011–2014)

## Dashboard Features
- Total Sales, Profit & Quantity KPIs
- Profit by Category
- Sales by Category
- Profit by Year
- Sales by Year
- Product-wise Sales Table
- Interactive Filters (Category, State, City, Year, Month, Day)

## Key Insights
- Analyzes sales and profit trends.
- Identifies top-performing product categories.
- Enables interactive filtering for better analysis.
- Supports business decision-making through visual reports.
