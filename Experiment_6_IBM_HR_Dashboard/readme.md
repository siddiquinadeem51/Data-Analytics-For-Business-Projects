# 📊 HR Analytics Dashboard

## Project Overview

This project was developed as part of an assignment to create an interactive **HR Analytics Dashboard** using the **IBM HR Analytics Employee Attrition & Performance** dataset. The dashboard provides insights into employee demographics, hiring trends, attrition, and workforce distribution to support workforce planning and employee management.

## Problem Statement

As an HR Data Analyst in a multinational organization, the objective is to analyze HR data and build an interactive dashboard that helps the HR department understand:

* Employee demographics
* Hiring trends
* Employee attrition
* Workforce distribution

The dashboard is designed to assist HR professionals in making data-driven decisions for workforce planning and employee management.

## Dataset

**IBM HR Analytics Employee Attrition & Performance Dataset**

Kaggle: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
